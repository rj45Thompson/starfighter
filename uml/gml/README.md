# The Starblast requirements model

Generated by `gml` (in [TDRE](https://github.com/rj45Thompson/TDRE), `src/gml/`) — a
program that finds the holes in a use-case model by arithmetic and asks a language
model to fill one at a time, checking every answer against this repository's own
source before admitting it.

Nothing in `run/` is hand-written. Every use case here cites a symbol that really
exists in `index.html` or a sibling module, or is marked `ABSENT`. The engine refuses
a citation it cannot resolve.

## What is here

| | |
|---|---|
| `starblast.spec.json` | the **seed** — five epics, each with the state it starts in and the state it must end in. The only hand-written input. |
| `answers/` | what the oracle replied, in full, addressed by target so the run is re-playable |
| `run/CHAIN.md` | **the linear story**, first action to last, with each beat's preconditions, postconditions, citation, and the question that put it there |
| `run/REQUIREMENTS.md` | the specification itself |
| `run/GAPS.md` | what is still open, by severity |
| `run/COVERAGE.md` | how much of the real source is accounted for, by three measures |
| `run/TRACE.md` | **the reasoning as it happened** — every question, every answer, and every answer that was refused and why |
| `run/model.gml` | the graph in Graph Modelling Language (yEd, Gephi, Cytoscape, networkx) |
| `run/usecases.mmd` | the same as a Mermaid flowchart |
| `run/model.json` | the machine-readable model; a later run resumes from it |

## Reproducing it

```bash
cd ../../..                     # to the parent of both repos
gml run  starfighter/uml/gml/starblast.spec.json --out starfighter/uml/gml/run --oracle transcript
gml answer-batch starfighter/uml/gml/answers/round1-epics.json --out starfighter/uml/gml/run
gml run  starfighter/uml/gml/starblast.spec.json --out starfighter/uml/gml/run --oracle transcript
```

With `ANTHROPIC_API_KEY` set, `--oracle auto` does the same thing without the
round-trip: the engine calls the API itself and the answers land in the cache.

## Where it stands

Five epics, **all five running end to end with no break in the chain**. Twenty-nine
use cases, thirty state literals, every one grounded in a symbol that resolves.

Coverage of the closed space is 22–64% per epic against a 90% gate, so the model is
a complete *spine* and not yet a complete specification: 161 symbols in scope are
still owned by no use case, and each one is a question the engine has already
written. That number is the honest measure of what is left, and it is a count that
has to reach zero rather than a judgement about whether the document feels finished.

## Two findings about this repository, from the extractor rather than from the model

The reader takes two independent readings of every config constant — where it is
declared, and everywhere it is read — and reports where they disagree:

- **`CFG.ROCK_NEAR_R` is read and declared nowhere.** `index.html` reads it; no such
  constant exists.
- **`CFG.BOT_IDLE_R` is declared and never read.** A dead knob.

Both were already known from `ASTEROID_USE_CASES.md`, found there by hand. The
extractor found them again from the source alone, which is the point: the check that
caught them is now a check that runs.

Eight further `READ_NEVER_DECLARED` findings are listed in `run/COVERAGE.md`.
